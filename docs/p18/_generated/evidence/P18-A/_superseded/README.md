# P18-A/_superseded —— 已退役的历史轮（不参与判定）

本目录存放 **P18-A 波次**在启用「按波次独立证据根」之前、被取代的历史证据轮。
它们**不是**「历史的失败轮」—— 每一轮都是当时的真实运行结果；退役的原因是**证据树布局
变更**，而非运行出错。

## 为什么退役

**变更前**：整个 P1.8 系列（P18-0 / P18-A / P18-B / …）共用同一个证据根
`docs/p18/_generated/evidence/P18/`。`evidence-run.mjs` 每次重跑都用同名 `<RunId>.txt`
覆盖上一轮产物，于是**每跑一轮，上一轮的 15 个产物就变成"顶层 orphan"**（累积到 27 个）；
而 `evidence-verify.mjs` 又把 orphan 写成恒真通过（`check(..., true, ...)`）+ 措辞
"历史失败轮留档" —— 这污染了证据语义（**orphan ≠ 历史失败**）。

**变更后**：恢复 P1.7 的**「按波次独立证据根」**原则 ——

- 证据根按波次独立：`docs/p18/_generated/evidence/<WAVE>/`（例：`P18-A` → `…/P18-A`）；
- 任务表按**族**共用：`P18-A` / `P18-B` / … 共用 `P18` 那份任务表；
- 每次生成前把**同任务**的旧产物 `rename` 进本目录（`_superseded/`，**不是删除**），
  并让 `RunId` 的 attempt 按代递增（`R01` / `R02` / …）；
- 于是**波次目录顶层恒等于 matrix 引用的那批文件**，orphan 才能成为严格判据
  （P18* 严格：出现 orphan 即 `BROKEN`；见 `scripts/evidence-verify.mjs`）。
