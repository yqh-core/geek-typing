## 一句话结论

本功能矩阵共约 **180 项**：约 **108 项已实现**（集中在打字练习 90%、背单词 88%、音效 80%、命令面板 75%、复习 73%）、约 **66 项未实现**（集中在安全/合规/运维 19%、导入体系 33%、主题令牌 44%、UI 侧搜索 0%）；最重要的结构性发现是存在**"能力已建、UI 未接线"的悬空层**——`Query` 四入口与 Index 6 个 finder 均有实现且有 149 例单测，但**零 UI 调用方**，UI 仍走遗留的 `wordBanks.ts` 直读词数组 17 处。
