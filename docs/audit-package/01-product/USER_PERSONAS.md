## 1. 关键事实：零用户调研

| 检查项 | 结果 |
|--------|------|
| 仓库内是否有用户调研文档 | ❌ 无 |
| 是否有访谈记录 / 问卷 / 用户反馈 | ❌ 无 |
| 是否有埋点 / 分析上报代码 | ❌ **无任何分析上报**（全仓无 fetch 上报端点） |
| 是否有用户系统（可反推用户规模） | ❌ 无登录、无账号、无后端 |

| 唯一间接线索 | 产品设计本身（默认词库、模式、文案） |

**推论**：由于**没有任何用户数据采集**，即便产品已上线，我们也**无法回答"谁在用、用多少、用得怎么样"**。这是本项目在产品侧最基础的空白。

**证据**：`docs/audit-package/12-infrastructure/MONITORING.md`（无监控）；`docs/audit-package/03-architecture/DATA_ARCHITECTURE.md` §4（数据全部留在本地 `localStorage`，无出网）。

## 3. 推断画像

> ⚠️ 以下三组画像均为**推断**，非调研结论。每组给出「推断强度」自评。

### 3.1 画像 A：技术英语学习者（主推断对象）

**推断强度：强**（依据 C-1、C-2、C-3、C-4、C-5、C-9）

| 维度 | 推断内容 | 依据 |
|------|---------|------|
| 身份 | 程序员 / 技术从业者 / 计算机相关专业学生 | C-1、C-2、C-3 |
| 年龄 | 未能推断（无任何数据） | — |
| 英语水平 | 有一定基础，但技术英语词汇（如 `idempotent`、`orchestration`）阅读有障碍 | C-1、C-3 |
| 核心痛点 | ① 技术文档/源码注释/commit message 里的英文读不顺；② 单词背了就忘；③ 用通用背单词 App 背的是生活词汇，与工作无关 | C-1、C-3、C-5 |
| 使用场景 | 工作日白天，在电脑前；也可能通勤时用手机滑卡片 | C-9、C-10 |
| 设备 | 主要桌面浏览器（支持快捷键）；辅以手机 | C-9、C-10 |
| 动机 | 提升读技术资料的速度，而非应试 | C-5 |
| 期望价值 | 背单词与"敲代码"这个已熟悉的动作绑定，降低启动成本 | C-5、C-2 |
| 反感的 | 社交、排行榜、打卡分享 | C-12 |

**关键推断**：这个画像的**核心假设**是"用打字这个动作来背单词，比单纯看卡片更有效"。这是产品的**第一性假设**，但**仓库内没有任何 A/B 或效果验证数据**。

---

### 3.2 画像 B：应试备考者（次要推断对象）

**推断强度：中**（依据 C-8，且与 C-1/C-5 的定位存在矛盾）

| 维度 | 推断内容 | 依据 |
|------|---------|------|
| 身份 | 考研 / 雅思 / 托福备考学生 | C-8（`kaoyan`/`ielts`/`toefl` 各 3,000 词） |
| 需求 | 大量词汇覆盖（应试要求数千词） | C-8 |
| 核心痛点 | 词汇量大、时间紧、需要高效重复 | C-8 |
| 使用场景 | 备考周期内每日固定时长 | C-14（每日目标） |
| 设备 | 可能更偏手机/平板 | C-10 |

**关键矛盾（必须指出）**：

| 矛盾点 | 事实 |
|--------|------|
| **内容体量不足** | 应试需数千词，但 CET4 覆盖率实测仅 **1.9%**（`KNOWN_ISSUES.md` CONTENT-001） |
| **词库同质化** | `ielts`/`kaoyan`/`toefl` 三包各 3,000 词，**全部来自同一 ECDICT 词频源**，很可能高度重叠，而非按考试大纲分档 |
| **字段缺失** | `partOfSpeech` **零数据**（CONTENT-005，**P1.6-E 已移除该字段声明**）；9 条空 `definition`（BUG-001）；音标**两套体系混用**（CONTENT-004） |
| **无考试功能** | `docs/audit-package/08-exam/` **空目录**；无模考、无题型训练 |

**结论**：虽然词库里有应试包，但**内容质量与产品功能都不足以支撑应试场景**。画像 B 更像是"词库来源的副产品"，而非有意服务的用户群。

---

### 3.3 画像 C：通用英语学习者（弱推断）

**推断强度：弱**（仅有 C-6、C-7 支撑，且被产品设计反向否定）

| 维度 | 推断内容 | 依据 |
|------|---------|------|
| 身份 | 泛英语学习者 | C-6「练英语」 |
| 需求 | 提升英语综合能力 | C-6 |

**为何是弱推断**：

| 反向证据 | 事实 |
|---------|------|
| 无听力 | 无音频内容类型；`07-media/` 空目录 |
| 无口语 | 只有 TTS 播放，无发音评测 |
| 无阅读 | 无文章/段落类型内容 |
| 无语法 | 无语法模块 |
| 无教材体系 | 词库为词频包，非课程编排 |

**结论**：slogan 里的"练英语"实际上只落到**打字 + 背单词**两个动作上；通用学习者所需的听说读写四项中有三项零实现。**画像 C 是被 slogan 暗示但产品未服务的人群。**

## 5. 画像推断的固有局限

| 局限 | 说明 |
|------|------|
| **无用户数据** | 产品无任何埋点，无法验证任一画像是否真实存在 |
| **无反馈渠道** | 无评价入口、无客服入口、无 issue tracker |
| **默认值偏好有限** | 默认词库是 `ai-core`，但用户完全可切换，无法从默认值推断真实分布 |
| **文案不等于设计意图** | slogan 提到"练英语"，但产品实际只做两个动作 |
| **无竞品对比** | 未做过竞品调研（见同目录 `COMPETITOR_ANALYSIS.md`），无法判断差异化定位是否成立 |
| **A/B 验证缺失** | "打字背单词比看卡片更有效"这一核心假设**无任何数据支撑** |

## 一句话结论

本项目**未做过任何用户调研且无任何埋点**，因此不存在可验证的用户画像；从产品设计（默认 `ai-core` 词库、`code` 模式、`ide` 主题、「敲代码一样背单词」文案）可**强推断**其目标用户是"技术英语学习者"，但应试画像因 CET4 覆盖率仅 1.9% 而匹配度低，通用学习者画像因听说读三项零实现而不成立——**"打字背单词更有效"这一核心产品假设在仓库内无任何验证数据**。
