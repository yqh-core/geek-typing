## 1. 键盘交互（主交互方式）

本项目**以键盘为第一交互方式**。核心设计意图（可由 slogan「敲代码一样背单词」印证）是让用户**双手不离键盘**。

### 1.1 全局键盘分发

`src/App.tsx:411-568` 的 `handleKeyDown` 是唯一的全局键盘入口。

| 判断顺序 | 条件 | 行为 | 出处 |
|---------|------|------|------|
| 1 | 命令面板打开（`commandMode`） | **让位**（不处理） | `:411-568` 首段 |
| 2 | 当前页签**非** `typing` | **让位** | 同上 |
| 3 | 按下 `Ctrl` / `Meta` / `Alt` | **忽略** | 同上 |
| 4 | 按下 `Enter` 且已完成 | **重开一轮** | `:444` 附近 |
| 5 | `spell` 模式且按下 `Backspace` | **退格** | `:432-438` |
| 6 | 非单字符输入 | **忽略** | 同上 |
| 7 | `code` 模式 | 用**原文**（不 lower） | `:388-397` |
| 8 | `spell` 模式 | 走**自由输入**分支 | 同上 |
| 9 | `classic`/`timed`/`code` | 走**严格纠错**分支 | 同上 |

### 1.2 严格纠错分支（classic / timed / code）

| 条件 | 行为 |
|------|------|
| `target.startsWith(next)` | 正确 → 字母变色（`correct` 槽） |
| 否则 | 错误 → `shake` 抖动 + 拦截（不推进） |
| 整词完成 | `lockRef` 加锁 + `settleReview` + **220ms 后** `advance` |
| `code` 模式 | `target` **不做 lower**（大小写敏感） |

**验证**：
- E2E【2】`1/20` → `2/20`（严格纠错 + 进度推进）
- E2E【13-1】样本代码行 `const [state, setState] = useState(initialState);`，**大写 `T` 被拦**

### 1.3 打字页快捷键汇总

| 键 | 行为 | 条件 |
|----|------|------|
| 任意字符 | 输入 | typing 页 |
| `Backspace` | 退格 | 仅 spell 模式 |
| `Enter` | 重开一轮 | 已完成 |
| `Space` | 输入空格 | classic 模式（作为普通字符） |

### 1.4 背单词页键盘流

`src/components/Memorize.tsx:101-138`

| 键 | 行为 | 备注 |
|----|------|------|
| **Space** | 翻面 | 带 `preventDefault`（防页面滚动） |
| **1** | 不认识（unknown） | 该词追加 **2 次** |
| **2** | 模糊（fuzzy） | 该词追加 **1 次** |
| **3** | 认识（known） | 完成出队 |

**验证**：E2E【9】unknown → 进度 `/22`；E2E【11.6】Space/1/2/3/Enter 全套

### 1.5 命令面板键盘流

`src/components/CommandPalette.tsx`（文件头注释 + 实现）

| 键 | 行为 |
|----|------|
| **Esc** | 打开 / 关闭（由 App 全局监听，**捕获阶段**） |
| **↑** | 选中项上移 |
| **↓** | 选中项下移 |

### 1.6 Esc 的三级让位机制（重要）

`src/App.tsx:367-385`，**捕获阶段（capture phase）**监听：

| 优先级 | 条件 | 行为 | 理由 |
|-------|------|------|------|
| **1** | 有下拉展开：`[data-testid^="dropdown-"][aria-expanded="true"]` | **不劫持** | 先关下拉 |
| **2** | 焦点在表单元素内 | **不劫持** | 不抢输入意图 |
| **3** | 其他 | **切换命令面板** | 主用途 |

**验证**：E2E【14-2】"命令态互斥"

**实现约束**：下拉必须带 `aria-expanded` 且 testid 以 `dropdown-` 开头，否则让位失效（`Dropdown.tsx:60`/`:61` 满足）。

## 3. 触摸交互

### 3.1 背单词卡片手势（本项目最复杂的交互）

`src/components/Memorize.tsx:145-258`，原生 `touchstart` / `touchmove` / `touchend`

| 手势 | 卡片状态 | 行为 |
|------|---------|------|
| **单击** | 未翻面 | 翻面 |
| **上滑** | 未翻面 | 翻面 |
| **左滑** | 未翻面 | 回弹 |
| **右滑** | 未翻面 | 回弹 |
| **下滑** | 未翻面 | 回弹 |
| **左滑** | 已翻面 | **不认识（unknown）** |
| **右滑** | 已翻面 | **认识（known）** |
| **上滑** | 已翻面 | **模糊（fuzzy）** |
| **下滑** | 已翻面 | 回弹 |

### 3.2 手势实现参数

| 参数 | 值 | 出处 |
|------|-----|------|
| 触发阈值 | `SWIPE_THRESHOLD = 60`（px） | `:37` |
| 跟手位移 | `translate` | `:145-258` |
| 跟手旋转 | ≤ **12deg** | 同上 |
| 粗指针门控 | `matchMedia('(pointer: coarse)')` | `:164` |
| 触摸能力门控 | `navigator.maxTouchPoints > 0` | `:145-258` |
| 合成 click 屏蔽 | `touchHandledAt` 时间戳 | 同上 |
| 最新回调引用 | `answerRef` | 同上 |
| 动画结束 | `flyOut`（飞离）/ `bounceBack`（回弹） | 同上 |

### 3.3 触摸事件监听选项（性能相关）

| 事件 | 选项 | 理由 |
|------|------|------|
| `touchstart` | `{ passive: true }` | 允许浏览器立即滚动 |
| `touchmove` | `{ passive: false }` | 需要 `preventDefault` 阻止滚动 |

**验证**：E2E【14-2】移动端 swipe（`touchstart`/`touchmove`/`touchend` 合成事件）

## 一句话结论

交互规格以**键盘为第一交互方式**：`App.tsx:411-568` 是全局键盘分发入口（按命令态 → 页签 → 修饰键 → 模式四层让位），背单词页有 **Space 翻面 / 1-2-3 三键打分 / K 重读 / Enter 重来**（`Memorize.tsx:101-138`，E2E【11.6】），命令面板有 **↑↓ 移动 / Tab 补全 / Enter 执行（带参命令只补全不误执行）**（E2E【14-1】），Esc 采用**捕获阶段三级让位**（下拉 `aria-expanded` > 表单元素 > 命令面板，`App.tsx:367-385`，E2E【14-2】）；鼠标为点击、无 tooltip 且**桌面鼠标无法滑卡片**（手势被 `isTouch` 门控）；触摸为**四向滑动**（未翻面时任意横竖滑均回弹，已翻面时左滑 unknown / 右滑 known / 上滑 fuzzy，阈值 `SWIPE_THRESHOLD = 60`、跟手 ≤12deg、`touchstart` 用 `{passive:true}`、`touchmove` 用 `{passive:false}`，E2E【14-2】）；下拉由父组件 `openId` 保证互斥；提示只有命令面板内的 `command-notice` / `command-error` 两种且**无 `aria-live`**，全部手势与 4 个 keyframes 动画**均不响应 `prefers-reduced-motion`**。
