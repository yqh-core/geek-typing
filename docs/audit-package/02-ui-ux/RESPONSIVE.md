### 2.2 断点

使用 **Tailwind 默认断点**（`tailwind.config.js` 的 `theme.extend` 中**无 `screens`**）：

| 前缀 | 最小宽度 | 典型设备 |
|------|---------|---------|
| （无前缀） | 0 | 手机 |
| `sm:` | 640 px | 大手机 / 小平板 |
| `md:` | 768 px | 平板 |
| `lg:` | 1024 px | 笔记本 |
| `xl:` | 1280 px | 桌面 |
| `2xl:` | 1536 px | 大桌面 |

**但注意**：截图视口为 390 / 834 / 1440，其中：
- **390 px** → 落在无前缀档
- **834 px** → 落在 `md:`（768）与 `lg:`（1024）之间
- **1440 px** → 落在 `xl:`（1280）与 `2xl:`（1536）之间

### 2.3 实测的响应式类名

#### 命令面板（最明显的响应式设计）

`src/components/CommandPalette.tsx:313`：

```
fixed bottom-0 ... sm:bottom-6 sm:left-1/2 sm:-translate-x-1/2 sm:max-w-xl
```

| 视口 | 表现 |
|------|------|
| 移动端（< 640px） | **底部贴边全宽**（`bottom-0`） |
| 桌面端（≥ 640px） | **居中浮层**，最大宽 `max-w-xl`（`bottom-6` + `left-1/2` + `-translate-x-1/2`） |

#### 命令面板输入框（防缩放）

`src/components/CommandPalette.tsx:332`：`text-base sm:text-sm`

| 视口 | 字号 |
|------|------|
| 移动端 | `text-base`（16px）—— **iOS Safari 不会因聚焦而缩放** |
| 桌面端 | `text-sm`（14px） |

**验证**：E2E【14-2】明确断言移动端命令输入框字号 ≥16px。

#### 移动端无横向溢出

**验证**：E2E【11】"移动端无横向溢出"断言。

### 2.4 触屏适配

| 项 | 实现 | 出处 |
|----|------|------|
| 粗指针检测 | `matchMedia('(pointer: coarse)')` | `Memorize.tsx:164` |
| 触摸能力检测 | `navigator.maxTouchPoints > 0` | `Memorize.tsx:145-258` 内 |
| 卡片手势 | 左/右/上滑 | `Memorize.tsx:145-258` |
| 手势阈值 | `SWIPE_THRESHOLD = 60` | `:37` |
| 跟手动画 | `translate` + ≤12deg `rotate` | 同上 |
| 合成 click 屏蔽 | `touchHandledAt` | 同上 |
| 滚动兼容 | start `{passive: true}` / move `{passive: false}` | 同上 |

**关键设计取舍**：移动端用**原生 touch 事件**而非 Pointer Events，也未用第三方手势库。

## 3. 未建部分（📐）

| # | 缺失项 | 说明 | 风险 |
|---|-------|------|------|
| R-1 | **自定义断点** | 无 `screens` 扩展，全用默认 | 断点与实际内容宽度无关（断点应"跟着内容走"，而非跟设备） |
| R-2 | **容器查询**（`@container`） | 无 | 组件无法响应自身容器宽度，导致同组件在不同容器里表现不一致 |
| R-3 | **逻辑属性** | 用 `ml-*`/`mr-*`/`text-left` 等物理属性 | 将来若加 RTL 语言需全量改写 |
| R-4 | **安全区内边距** | 无 `env(safe-area-inset-*)` | 移动端底部固定的命令面板可能与全面屏手势条重叠 |
| R-5 | **横屏适配** | 无针对 `orientation: landscape` 的处理 | 横屏时打字区可能过矮 |
| R-6 | **超宽屏适配** | 无最大宽度约束说明 | 在 2560px+ 屏幕上文本行可能过长 |
| R-7 | **响应式图片** | 无 `srcset`/`picture` | 当前无图片资源，但 PWA 图标仍存在（`public/`） |
| R-8 | **打印样式** | 无 `@media print` | — |
| R-9 | **触摸目标尺寸规范** | 无 | 移动端小按钮可能 <44×44px（**未逐一测量**） |
| R-10 | **视口单位适配**（`dvh`/`svh`） | **未验证**是否使用 | 移动端浏览器工具栏收起/展开可能导致 100vh 抖动 |
| R-11 | **响应式截图门禁** | 截图由 `audit-capture.mjs` 手动/脚本运行，**不在 CI** | 响应式回归无自动拦截 |
| R-12 | **review / progress 移动端截图** | **缺失** | 这两页移动端表现无证据 |
| R-13 | **平板专门优化** | tablet 834px 落在 `md`/`lg` 之间，无专门设计 | — |
| R-14 | **字体随视口缩放**（`clamp()`） | 无 | 打字区字母字号在小屏可能偏小（**未测量**） |

## 一句话结论

响应式现状是**"移动端有实用适配、但无响应式体系"**：有三档视口截图证据（1440×900 / 834×1112 / 390×844，共 17 张，由 `audit-capture.mjs` 249 行生成）、E2E【11】有"移动端无横向溢出"断言、【14-2】有"命令输入框 ≥16px"断言、卡片支持原生 touch 滑动（`Memorize.tsx:145-258`）；但 `tailwind.config.js` **无自定义断点**（全用默认）、**无容器查询**、**无安全区处理**、**无触摸目标规范**，且响应式类名实测**集中在命令面板**（`sm:bottom-6 sm:left-1/2 sm:-translate-x-1/2 sm:max-w-xl` / `text-base sm:text-sm`）、**review 与 progress 两页在 tablet/mobile 下无截图**、截图脚本**不在 CI**（`deploy.yml` 只 build；`e2e.yml` 仅 PR）——即响应式回归**无自动拦截能力**。
