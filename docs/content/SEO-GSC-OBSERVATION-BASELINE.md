## 五之二、下一观察周期的判定门槛（**2026-10-06 冻结 · 看数据之前定死**）

⚠️ **本节的价值全在「前置」。** 若等数据回来再定门槛，门槛会被定成刚好能解释现状的样子。
**以下判定在拿到第一批 GSC 数据前就已写定，此后不得因数据难看而放宽。**

### 依据（Google 官方口径，非本项目估计）

| 事实 | 官方表述 |
|---|---|
| 提交后立即抓取 | Google 在收到 sitemap 后**立即尝试抓取**；若失败会在**数天内**持续重试，成功后按自身节奏反复重抓 |
| `Discovered - currently not indexed` | Google 已发现该 URL 但**尚未抓取**。官方解释：抓取会给站点带来过载，故**重新安排了抓取时间** ⇒ 这是**抓取调度问题，不是内容判决** |
| `Crawled - currently not indexed` | Google **已抓取**该页但**决定不收录**。官方明确：**无需重新提交该 URL** |
| 单页问题不阻塞 sitemap | 只要 sitemap 大体可抓取可读，**个别 URL 的问题不会阻止 Google 继续读取 sitemap** |
| 低质量页面的典型形态 | 官方列举：过时内容、站内搜索框生成页、**应用过滤器生成页**、重复内容、自动生成内容 |

> 🕐 **时间门槛（业界经验值，非 Google 承诺）**：sitemap 状态变Success 数小时～1 天；
> URL discovered 约 1–7 天；新站首次收录通常 2–6 周。
> **本项目只有 14 个 URL、站点权重近零** ⇒ 取区间下沿之外不判失败，但**也不因此放宽 canonical 红线**。

### 门槛 A：canonical 一致性（**红线 · 唯一可立即判定失败项**）

| 观测 | 判定 | 动作 |
|---|---|---|
| `User-declared canonical` == Day 0 本地声明值（§四之二） | ✅ 一致 | 记录，**继续等** |
| `User-declared canonical` ≠ 本地声明值 | 🔴 **失败** | 立即立刀（我方或 Google 侧有偏差，属可判定缺陷） |
| `Google-selected canonical` == `User-declared canonical` | ✅ 规范化闭环成立 | 记录 |
| `Google-selected canonical` 指向别的地址 | 🟡 **观察项 O-SEO-09** | ⛔ **不重开 Path C**。先看是否同批 308 规范化未完成；仅当**持续多次巡检仍偏离**才升级 |
| 出现 `Alternate page with proper canonical tag` | ✅ **预期正确行为** | 记录，**不是**问题 |

> 🔴 **canonical 是唯一「不需要等数据成熟就能判失败」的红线。** 其余一切都可以等。

### 门槛 B：收录状态是否与页面形态相符（**不是「收录 = 好」**）

**先认状态类型再判好坏** —— `Discovered` 与 `Crawled` 是方向相反的两件事：

| GSC 状态 | 含义 | 是否失败 | 正确动作 |
|---|---|---|---|

| `Crawled - currently not indexed` | 抓了，**判不收录** | 🟡 **内容层信号，不是技术缺陷** | ⛔ **不重开 Path C**；仅记录哪个包被拒（推测与厚度相关，见下表） |
| `Excluded by robots.txt` | 被拦 | 🔴 **失败** | 但本地已实测零 Disallow ⇒ 若出现必为 Google 侧异常，立刀 |
| 404 / 5xx | 抓取失败 | 🔴 **失败** | 但本地 14/14 = 200 ⇒ 若出现立刀 |
| `Duplicate without user-selected canonical` | 判重复 | 🟡 观察项 | 记录，⛔ 不重开 |
